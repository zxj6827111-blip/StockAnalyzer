## 1. 判定

| | |
|---|---|
| **主判据 verdict** | **`MERGE_INCONCLUSIVE`** |
| 一句话 | 三个权重的点估计**全部为正**（+0.007 ~ +0.013），但主判据 w=0.50 的配对 CI 跨 0 → **没有证据说合并更强**；也不能说更差 |

| 判据条件 | 实测 | 过否 |

| ΔIC(w0.50 − model) 配对 CI 下界 > 0 | −0.0076 | ✗ |

**结论**：合并**没有**显著优于模型；但点估计方向一致且量级（+0.013）是噪声地板的 7 倍，
说明这不是"无效应"而是**当前证据量不足**——342 个交易日的配对 CI 半宽约 ±0.022，
要分辨 0.013 的效应需要更长的独立样本。

## 3. 与 C3 的关系：端点在同一次运行内算，差异落在噪声内

| | C3（两次独立运行） | C6（同一次运行内） |
|---|---|---|
| model IC | 0.0612 / 0.0624 / 0.0634 | 0.0628 |
| reversal IC | 0.0578 | 0.0578（逐位相同） |
| model − reversal | +0.0007（跨两次运行） | +0.0050 [+0.0380, +0.0441] 跨 0 |

两条独立路线得到同一结论：**模型与反转基线在本窗口内水平不可辨**（CI 都跨 0）。
C6 的端点同源设计消除了跨运行训练噪声，但仍不足以把二者分开——差距本来就在噪声量级。

## 4. 一次真实的口径漂移（过程留痕，值得复用）

首次实跑（`/tmp/c6out`、`/tmp/c6out2`）得到 model IC **0.0825 / 0.0802**，而 C3 三次是
**0.0612 / 0.0624 / 0.0634**。差 0.019，是 0.0019 噪声地板的 10 倍。

定位过程（两条判据把范围锁死）：

1. `anchor_reversal` 的 IC 与 C3 **逐位相同**（0.05779939947337951）→ 数据、fold 切分、
   IC 实现、评估路径全部一致，差异只能在**训练**；
2. 宿主 `nproc=8`，与生产容器 `OMP_NUM_THREADS=8` 相同 → 排除线程；
3. 逐项比对后定位到**训练标签**：报告里的 `dataset.label_basis` 是**数据集**属性（来自
   `pit_meta`，两次都是 `return_rank`），**不是训练用的标签**。训练标签来自
   `cfg.labels.basis`，生产容器由 `SA__LABELS__BASIS=return_rank` 覆盖，而抛壳容器没带
   这个变量 → 训的是 `soup` 标签。

修正：实验容器必须带上与生产一致的 `SA__LABELS__BASIS=return_rank` 与
`SA__TRAINING__TEST_RATIO=0.2`；并在报告里落盘「训练口径指纹」（线程环境、库版本、
`training_params`、`labels.basis/horizon_days`）。带上后 model IC = 0.0628，与 C3 一致。

**可迁移经验**：报告里名字最像「标签」的那个字段可能不是训练读的那个标签；跨运行比较
之前，必须让**训练口径**（标签、比例、线程、库版本）随报告落盘，否则"同一个 harness 跑
出来的数"根本不是同一个东西。这条已写进 harness（`_environment_fingerprint`）与预注册 §10。

## 6. 结论与下一步

1. **合并不显著更强**（主判据 INCONCLUSIVE），点估计为正但 CI 跨 0。**不得**据此说
   "合并有效"或"合并无效"——证据不足，不是反证。
2. 「模型 vs 反转因子」在本窗口同样**不可辨**（两条独立路线一致）。§5.2 的残差诊断显示
   两者近乎正交（反转只解释模型排序方差的 10~15%），所以合并的点估计为正**与**正交性
   一致；缺的是样本量，不是机制。
3. 下一步若继续这条线，性价比最高的是**扩大独立样本**（更长窗口/更多不重叠 fold），
   而不是继续调权重——权重维度已经证明是平的（0.25/0.50/0.75 三个点估计彼此差 ≤0.007，
   都在噪声附近）。
4. 本结果**不改变**「return_rank 保留研究方向、自动训练与自动晋升均关闭」的现状。
