# C6 合并实验预注册：模型分数 × 反转因子（秩空间合并）

> **本文件在任何一次合并实验运行之前写好并冻结**。参数、判据、网格均在此钉死；
> 看完结果再改任何一项，等于事后挑参数，结论作废。
> 上游：`docs/learning_chain_c3_variant_results_20260915.md` §5.2（残差诊断）与 §8.3。

## 1. 要回答的问题（单一问题）

**每日把模型分数与 `−ret_20d` 各自横截面秩标准化后合并，合并信号的 IC 是否显著高于二者？**

上游证据（决定本实验值得做）：

- 模型（`raw_blend`）与固定反转基线（`−ret_20d`）**水平不可辨**：0.0624 vs 0.0578，
  配对 ΔIC +0.0007、CI 跨 0，且低于 0.002 的噪声地板；
- 但反转因子只解释模型排序方差的 **10~13%**（R²=0.1023 / 0.1327），残差 IC 与水平 IC
  几乎相同（0.0604 vs 0.0599、0.0616 vs 0.0624）、CI 均不含 0。

两条合起来：**近乎正交而水平相当** → 合并的期望增量最大。这是当前性价比最高的一次验证。

## 2. 合并定义（冻结）

对每个评估日的横截面，记当日有效样本集为 **S**（见 §3）：

```
z_model = (rank_average(score) - 0.5) / n        # 均匀秩分数，落在 (0,1)
z_rev   = (rank_average(-ret_20d) - 0.5) / n
merged(w) = w * z_model + (1 - w) * z_rev
```

- 秩用 **average** 处理并列；秩分数取**均匀** `(r-0.5)/n` 而不是标准正态分数——
  均匀秩是**单调不变**的（对任何严格单调变换结果相同），因此是纯秩空间的合并，
  不受分数刻度影响；正态分数会额外引入一个未注册的变换选择。
- `score` 用 C3 的优胜变体 **`raw_blend`**（校准前），训练与折结构完全沿用 C3。

### 预注册权重网格（冻死）

| 角色 | 权重 w | 说明 |
|---|---|---|
| **主判据（primary）** | **0.50** | 等权合并——**唯一无参数**的选择，不接受"试出来的"权重 |
| 描述性 | 0.25 | 偏反转 |
| 描述性 | 0.75 | 偏模型 |
| 端点（锚） | 1.00 = 模型 | 同一次运行内计算（见 §4） |
| 端点（锚） | 0.00 = 反转 | 同一次运行内计算（见 §4） |

0.25 / 0.75 只作**描述性**报告，**不参与**判据，也不允许"挑最好的那个权重"下结论。

## 3. 有效样本集 S（冻结）

`S = {rows: score 有限 ∧ ret_20d 有限 ∧ fwd_return 有限}`，当日 `|S| < 5` 的交易日跳过
（与残差诊断的样本下限一致）。**五个口径（三个权重 + 两个锚）用同一个 S**，所以
它们天然配对。

被 S 额外剔除的行数（相对主 IC 口径 `score` 有限 ∧ `fwd_return` 有限）必须逐 fold
计数并汇总上报 `rows_excluded`：若该数不为 0，合并口径的横截面就比主口径小，
结论必须带着这个差异读，不得当成同一横截面。

## 4. 为什么端点必须在同一次运行内算（重要）

C3 的 `raw_blend`（0.0612）与 `reversal`（0.0578）是**两次独立运行**的结果。LightGBM
多线程非确定性带来的**同配置复跑噪声地板是 0.0019**（C3 §5.1）——正是我们要检出的
效应量级本身。拿两次运行的数做配对，配对差里会混进训练噪声，检验没有意义。

因此本实验把权重网格与两个端点**放进同一次 fold 运行的同一段代码**，模型分数只训练
一次、只算一次 → 配对差里**不含**跨运行噪声。这也使端点 IC 与 C3 报告不逐位相同
（同一模型、同一口径，但训练实例不同），差异应落在噪声地板内，报告里并列给出以便核对。

## 5. 判据（冻结；先写判据再看数）

对**主判据 w=0.50**，令
`Δ_model = IC(merged 0.50) − IC(anchor_model)`，`Δ_rev = IC(merged 0.50) − IC(anchor_reversal)`
（均为**同日配对**的逐日差值序列，再按 §6 求 CI）：

| verdict | 条件 |
|---|---|
| `MERGE_GO_CANDIDATE` | `Δ_model` 的配对 CI 下界 > 0 **且** `Δ_model` 均值 ≥ 噪声地板 0.002 **且** `Δ_rev` 的配对 CI 下界 > 0 **且** `IC(merged 0.50)` 自身的 CI 下界 > 0 |
| `MERGE_INCONCLUSIVE` | 上述任一不成立，但 `Δ_model` 的配对 CI **跨 0** |
| `MERGE_NO_GO` | `Δ_model` 的配对 CI 上界 < 0（有负向证据） |

附加的**稳定性闸**（防"只在某一个权重上赢"的多重比较假象）：
若 0.25 / 0.50 / 0.75 三个权重相对 `anchor_model` 的 ΔIC **符号不一致**，则即使主判据
通过也降级为 `MERGE_INCONCLUSIVE`，并在报告里标 `grid_delta_signs_consistent=false`。

其他前置条件（任一不满足则本实验的 verdict 不可用，标 `invalid_reason`）：

- `--merge-grid` 必须开启；未开启时报告该节为空并写明原因，不得当成"未通过"；
- `lookahead_violations_total == 0`；
- `folds_completed >= 4`、覆盖门（块数 ≥ 2）通过。

## 6. 置信区间口径（与 C3 一致，不另立一套）

- 逐日值序列 → **连续交易日块** moving-block bootstrap，块长沿用 C3 的 `ci_block=5`，
  `n_boot=1000`、`seed=20260905`、95%；
- 配对差：先按交易日取差（任一侧缺失则丢弃该日，丢弃数上报 `unpaired_days`），
  再对差序列做同一个 bootstrap。**不得**对两条序列各自求 CI 后比较区间重叠与否
  ——那不是配对检验。

| 项 | 值（与 C3 完全一致，否则不可比） |
|---|---|
| 数据 | `artifacts/phase2_label_remediation/pit_dataset_rank`（24 分片，2,405,272 行） |
| fold | 18 折、`train=120 / test=20 / step=5 / embargo` 由数据派生 |

| 量级参照 | 噪声地板 **0.0019**（C3 §5.1 两个同配置复跑目录的实测差） |
| 口径限定 | **214 特征世代 / 全市场资格集 / 流程级评估**，与 C3 同世代可比 |

**不是独立证据、不构成晋升依据**：选择窗口与评估窗口仍是同一段历史（该窗口参与过
标签/特征/面板的开发），本实验只回答"合并是否更强"，不回答"模型是否有效"。
效力级的绝对判断仍归批次 D 的冻结工件前向 shadow。

## 8. 允许与不允许的推论

允许：
- 合并信号相对两个端点的**配对** IC 增量及其 CI；
- 三者是否在统计上可分（含"不可分"这一结论本身）。

不允许：
- 用 0.25/0.75 里最好的那个下结论（多重比较；仅描述性）；
- 把每日收益均值复利成年化（口径见 C3 §4）；
- 从本实验推出"模型/反转因子有效或无效"；
- 把结论外推到 222 特征世代或生产 sample-store 链路。
