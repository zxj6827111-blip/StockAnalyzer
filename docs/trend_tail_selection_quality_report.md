As-of: 2026-10-08 @ HEAD `a53032a`（分支 `feat/stock-selection-quality-overhaul`，PR #105）

本报告是改进计划 §5 要求的"验证报告"交付物。**结论是质量门未通过**，

## 2. 六个评价指标（成熟标签，池内）

| 指标 | 读数 |
| --- | --- |
| 净盈利率（池内、无条件、已扣冻结费用与滑点） | **37.78%**（1,036 / 2,742） |
| 成交率 | **48.9%**（2,742 / 5,613） |
| 未成交原因 | `below_lot_size` 2,801、`limit_up_locked` 70 |

| 资金占用 | 参考额 10,000 元/只；`Top-3` 每日 3 只 → 单日占用 30,000 元，282 笔样本合计名义 282 万元 |

`below_lot_size` 占未成交的 97.6%：**1 万元参考额在高价股上买不满 100 股一手**，
这本身就是链路质量的一部分（不是缺陷），也是成交率上限的主要约束。

## 3. ≥4 折滚动训练：门在这里停机，不产出命中率

`validate_tail_selection_quality.py`（LR 基线、4 折、独立校准段）：

| 特征配置 | 校准窗口 raw AUC | 结果 |
| --- | --- | --- |
| 四组合并（30 列） | 0.4990 | `TailTrainingError` → 停机 |
| market_relative | 0.3657 | 停机（方向为负） |
| trend_position | 0.4629 | 停机 |
| volume_liquidity | 0.4744 | 停机 |
| volatility_overheat | — | 训练矩阵遇 null → `TypeError`（该组内 `close_position` 有 11 条空值，验证器拒绝填零） |

**这是 §3.3 要求的行为**："新模型原生训练或身份验证失败时停止，不静默切换替代模型"，
训练器宁可不输出也不产出一个塌缩概率模型。因此本轮**没有** 4 折命中率数字，
也不会有"通过历史开发验证"的冻结模型。

### 对 §4 默认改进目标的逐条判定

| 计划要求 | 判定 | 依据 |
| --- | --- | --- |
| ≥4 个测试折、标签真实成熟 | **未满足** | 折内训练全部停机（§3）；标签成熟本身已满足 |
| 净盈率较匹配基线提升 ≥5pp | **不满足** | 最好 +1.58pp（`excess_ret_20`），`amount_to_float_cap` 最好也只有 +4.42pp 且 CI [0.36,0.50] 覆盖基线 |
| 差值分块 CI 下界 > 0 | **不满足** | 上表所有 CI 均跨 0 差值区间，无一严格大于基线 |
| 平均净收益为正 | **不满足** | 10 个排序字段的平均净收益**全部为负** |
| 尾部风险不明显恶化 | 不适用 | 没有通过的门，无对照对象 |
| 旧完整链路对照 | **如实报缺** | 历史归档没有当时的 composite_score/等级留档，旧排序无法重放；本轮对照用的是明确命名的可复现容量/风格分，**不冒充旧综合分** |
| 旧链路成交样本 | **如实报缺** | 生产侧 `funnel_trace_*.json` 计数为 0，旧链路从未留下可核对的成交留档 |

## 5. 状态与后续（AGENTS.md §9.1 口径）

- **工程验收：通过**（13 个场景 + 本轮新增生产者/fail-closed 行为均有测试钉住；
  `ruff` 全绿；已知环境性红灯一条：研究库被写入进程持锁时 CLI 测试退 1）。
- **选股质量验收：已测量、未通过。**不是"测不了"，是"测出来不够"。
- **冻结模型 / 影子验证：不启动。** §4 明令"不因历史数字漂亮而上线"；
  这里历史数字不漂亮，同样不能上。影子 60 天 / 100 笔必须是**未来真实观察**，
  本轮全部读数都是 `replayed_recompute`，不能顶替（两类样本混算会把结果抬高一个量级）。
- 生产未做任何改动：未部署、未重启容器、未改生产仓库与 marker；NAS 侧只有
  `/tmp` 下一个补采 CSV。

### 这份数据指向的三个下一步（按性价比）

1. **入场规则本身在亏钱**：所有排序的平均净收益都是负的，说明损失主要在
   "尾盘追高 + 5 日持有 + 费后"这个结构里，而不在排序里 —— 下一轮该改的是
   确认谓词/退出规则（同一契约、同一条代码路径），不是再换一个模型。
2. **成交率天花板**：97.6% 的未成交来自一手门槛。参考额 1 万元与高价股不兼容，
   要么按流动性分档设参考额，要么显式承认这部分候选根本不可表达。
3. **特征契约里两列日内信息一直没填**：`last30_volume_share` / `tail_volatility_ratio`
   现在**有分钟数据可以真算**了（分钟库已就位），补进 as-of 计算后四组里
   最缺的"日内结构"才第一次真正参与检验。
