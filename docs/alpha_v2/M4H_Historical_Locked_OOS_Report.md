### 9.1 成本口径（本轮修正）

原先此处写作"往返交易成本率约 0.13%（佣金 0.0003 + 印花税 0.0005 + 过户费 0.00001
+ 滑点 0.0015），即超额收益尚不足以覆盖交易成本"。该表述有**两处错误**，已按系统正式
成本模型更正：

| 项 | 权威取值 | 来源 |
|---|---|---|
| `cost_model` | `round_trip_rate_from_matcher_config` | `OutcomeSpec.to_payload()` |
| 买入侧费率 | 0.00031 | `ExecutionMatcher.estimate_cost("buy", …)` |
| 卖出侧费率 | 0.00081（含卖出印花税 0.0005） | 同上（`stamp_tax_apply_on = sell_only`） |
| **往返费用率** | **0.00112（0.112%）** | `round_trip_cost_rate()`，参考名义 100,000 |
| 滑点 | 0.0015 / 边，**按价格生效**（买 ×1.0015、卖 ×0.9985） | 协议声明值（`--slippage-ratio` 默认 = `static_slippage_ratio("trend")`），作用机制见 `ExecutionMatcher.apply_slippage` |
| **往返总摩擦** | **≈ 0.00412（0.412%）** | 费用 0.112% + 双边滑点 ≈0.300% |

> **一项覆盖缺口（据实记录）**：逐票预测的工件投影里没有 `entry_price_net` 列（落盘值恒为空），
> 因此**无法**从落盘工件反算真实生效的入场滑点——上表的 0.0015 来自**协议声明 + 代码路径**，
> 不是实测值，`cost_reconciliation.entry_slippage_measured_median` 因此为 `null`。
> 这不影响费用率（0.112% 由 `round_trip_cost_rate()` 直接算出）与下面"费用在超额中抵消"
> 的两项检验。

**错误一（算术）**：列出的分项相加是 0.231%（含滑点 0.0015 单边）或 0.412%（滑点双边），
都不是 0.13%；而权威费用率是 **0.112%**。0.13% 既不对应分项之和，也不对应系统口径。

**错误二（范畴）**：**"超额收益 < 交易成本"不成立为一个检验**。基准层是同一
`net_return_{h}d` 列的池内等权均值，而 M4-H 的费率在全样本是**常数**，于是

```
excess = net_i − mean_pool(net) = (gross_i − c) − mean_pool(gross − c) = gross_i − mean_pool(gross)
```

费用 `c` **精确抵消**——超额里根本没有成本可供覆盖。本轮已用落盘数据直接检验（不是推论）：

- 同一 `decision_date` 内 `net − excess`必为常数：**435 个决策日，最大组内极差 3.9e-16**；
- 费率平移不变性：把 `net_return_5d` 整体平移 0.0005（等价于换一个常数费率）后重算
  Top1 超额，结果 **0.0011391359169978788 → 0.0011391359169978781，差 6.5e-19**。

**正确读法**：超额衡量的是"相对全池等权的选择能力"（以费用中性方式），要判断经济
可用性必须看**绝对净收益**——见上表：三个 K 全部为负，且绝对命中率不足 50%。
结论方向未变（TopK 无经济价值），但**理由从"超额覆盖不了成本"更正为"绝对净收益为负"**；
后者是可直接复算的量，不依赖那个被证明无效的比较。

逐折看更清楚：29 折中 Top1 超额为正的只有 **15 折（52%）**，
中位数为 **+0.00002**（几乎为零）。

## 14 Calibration

概率校准层（`--phase b`，29/29 折完成）对四个方向头做 isotonic 校准，报告 Brier / ECE /
可靠性分箱。

**方法学**（满足协议 §5 的"校准严格早于 test"）：

- 概率头在**训练窗**上拟合（`HeadFitSpec`，与主模型同种子/同确定性设置）；
- 校准器在 **train 尾部独立切出的校准窗**上拟合，与训练窗互斥
  （实测校准窗 56,419 ～ 100,532 行，逐折 `pool_composition` 可查）；
- 预测时把**校准行 + 测试行一起**送入——只给测试行会让 isotonic 无可拟合样本而静默跳过；
- `calibration_violations = 0`（校准行出现在 test 窗内 0 次）。

**结果（29 折均值）**：

| 概率头 | Brier | ECE | 常数基准 Brier | 对比 |
|---|---|---|---|---|
| `p_up_net_3d` | 0.2470 | 0.0834 | 0.2405 | **劣于常数** |
| `p_up_net_5d` | 0.2511 | 0.0883 | 0.2411 | **劣于常数** |
| `p_up_excess_3d` | 0.2468 | 0.0199 | 0.2464 | 劣于常数 |
| `p_up_excess_5d` | 0.2464 | 0.0220 | 0.2460 | 劣于常数 |
| `p_up_net_3d_calibrated` | 0.2504 | 0.0774 | 0.2405 | 劣于常数 |
| `p_up_net_5d_calibrated` | 0.2522 | 0.0827 | 0.2411 | 劣于常数 |
| `p_up_excess_3d_calibrated` | 0.2468 | 0.0210 | 0.2464 | 劣于常数 |
| `p_up_excess_5d_calibrated` | 0.2463 | 0.0219 | 0.2460 | 劣于常数 |

（"常数基准" = 永远输出该折该头的基准概率 `base_rate`，其 Brier 为 `p(1−p)`。）

**三个读数**：

1. **区分度不足**：29/29 折 × 8 个头，**没有任何一个**的 Brier 优于"永远猜基准概率"。
   方向概率头在本阶段的历史锁定样本上**没有可用的预测增量**。
2. **校准机制本身有效**：`p_up_excess` 两头的 ECE 仅 **0.020–0.022**（预测概率与实际频率
   高度吻合），说明 isotonic 工作正常、`not_available` 的替代品并不存在——
   差距不是校准器造成的，而是**底层模型在绝对方向维度上没有区分度**。
3. **校准不改善 Brier**：isotonic 后 ECE 普遍下降（如 `p_up_net_3d` 0.0834 → 0.0774），
   但 Brier 没有改善（0.2470 → 0.2504）。这与 isotonic 的优化目标一致——它优化的是
   概率与频率的一致性（校准），而非判别力；底层无区分度时，校准会把概率拉向基准率，
   Brier 因此趋近常数基准。

**与 §13 的对照（本报告最重要的内部张力）**：同一个模型、同一批样本，
**横截面排序**的 IC 强且稳定（29/29 折为正，pooled CI95 不含 0），
**绝对方向概率**却无预测增量。一致的解读是：模型学到的是"谁比谁更好"的相对信息，
**不是**"市场会不会涨"的绝对信息——前者是横截面 Alpha 命题，后者是择时命题。
两者不是同一件事，本阶段证据只支持前者。

**确定性交叉验证**：phase A 与 phase B 的 29 个配对折中，已比对的 26 折
5D Rank IC **逐位相同**（差 0.00e+00），证明概率头是**纯附加层**、不改变主线模型，
且整条链路在固定种子下完全可复现。

## 23 Interpretation

本阶段的证据呈现出**一个清晰但内部有张力的画面**。

**张力**：排序能力（Rank IC）显著、稳定、跨年跨折跨 regime 一致为正，
且三种统计口径（bootstrap / Newey-West / 非重叠锚点）的 CI 都不含 0；
分位单调性完美（rho = 1.0），Winner Recall 为 1.0。
**但**把这种排序能力折成"买最前面几只"的收益时，5 日超额只剩 0.10–0.20%，
**绝对净收益为负（−0.15% ~ −0.24%）**，绝对命中率 43–45%，风格匹配后超额降到 0.04%，
而上行收益远小于下行风险（平均 MAE −4.3%、5% 尾部 −9.0%、Top5 最差 −39.9%）。

**可能的解释（按证据强度排序）**：

1. **排序信息集中在截面中部而非极端**。IC 是全截面统计，TopK 只看最极端的一小撮；
   分位均值从 Q1 −0.33% 到 Q5 +0.13% 的走势虽然单调，但**极值端并未放大**
   （Q4 +0.118% 与 Q5 +0.132% 几乎相同）。这与"模型能区分好坏、但无法识别最好的那几只"
   一致。
2. **摩擦远大于选择优势**。5 日持有期的往返总摩擦约 **0.41%**（费用 0.112% + 双边
   滑点 ≈0.30%），而模型相对全池等权的优势只有 **0.10–0.21%**；相抵之后 Top-K 的
   绝对净收益落在 **−0.15% ~ −0.24%**。这是"优势不足以覆盖摩擦"的**算术**，与 §9.1
   更正的结论一致——**不要**把它写成"超额 < 成本"，超额本身不含摩擦。
3. **风格暴露贡献了可观部分**。风格匹配层把超额压到 +0.04%，说明板块/市值/波动/动量
   风格能解释大部分截面差异。

**不能推出的结论**：不能说"模型无效"（IC/单调性/召回的证据强度不支持），
也不能说"模型可用"（TopK 经济意义、风格中性化、尾部风险都不支持）。

**一项独立的正向发现**：ML 相对**简单因子基线**的 IC 优势达 +0.107
（+0.071 vs −0.036，29/29 折 vs 8/29 折），说明模型确实学到了横截面信息，
而非复述常见的量价因子。但这份优势在 Top1 收益上只兑现了 +0.0006。

## 24 What This Evidence DOES Support

在 `LOCKED_OOS_ELIGIBLE` 区间（2016-01-04 ～ 2025-05-30，contamination 未证明）内：

1. **历史锁定样本上的横截面排序能力存在且稳定**：29/29 折、8/8 年、全部主要 regime
   的 5D Rank IC 为正，pooled CI95 不含 0。
2. **该排序能力不是常见量价因子的复述**：同一批折上显著优于无训练的简单基线

## 25 What This Evidence DOES NOT Support

1. **不构成生产可用性证据**：本阶段没有 `production_equivalent` 漏斗名册，
   质量池来源是 `research_proxy`（§20）。
2. **不构成经济可用性证据**：Top1/Top3/Top5 的 5D **绝对净收益为负**
   （−0.243% / −0.205% / −0.152%），绝对命中率 43–45%，风格匹配后超额近乎消失
   （+0.04%）。注意理由**不是**"超额覆盖不了成本"——超额里费用已被基准精确抵消
   （§9.1），该比较不成立。
3. **不支持"存在可交易 Alpha"的表述**：IC 显著 ≠ 组合收益显著；本阶段**未**做组合层
   回测（仓位、换手、容量约束）。
4. **不覆盖任何不受幸存者偏差影响的结论**：退市标的完全缺席，
   所有多年结果都是"存活者条件分布"。
5. **不代表未来**：2025-06-02 之后（含生产窗口）不在本证据范围内。
6. **概率校准已评估，但不建立绝对方向能力**：§14 的 Phase B 已完成四个方向头的
   isotonic 校准评估（Brier / ECE / 可靠性分箱齐备）。部分头的校准误差很低
   （`p_up_excess` 两头 ECE 仅 0.020–0.022，说明校准机制本身工作正常），但
   **八个头在 29/29 折上的 Brier 全部劣于对应的常数概率基准**，因此
   **没有建立任何增量的绝对方向（择时）预测能力**。此处**不是** `not_available`。
7. **不授权任何生产动作**：见 §27。
