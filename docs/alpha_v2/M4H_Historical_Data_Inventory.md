## 4. 幸存者偏差（不可修复）

入库证据：

```
symbols_with_last_bar_before_2025_01_01 = 0
symbols_with_last_bar_before_2026_01_01 = 0
symbols_with_last_bar_before_latest_minus_30d = 4
name_contains_delisting_marker = 2
staleness_days_by_symbol_p99 = 3.0
```

已知退市代码直接探测（全部 0 行）：

```
600401.SH / 600401 / 000418.SZ / 000418 / 600806.SH / 600806  →  0
```

**结论**：库内 5,198 只标的是"活到 2026 的完整名单"，十年间退市的标的**完全缺席**。
任何跨多年的横截面评估都带幸存者偏差。

**严重度：UNMITIGABLE**——本阶段无法修复，只能在报告中如实标注，并限制由此得到的结论强度。

另：`security_status` 与 `security_identity_mapping` 两张表**均为 0 行**，因此不存在可用的上市/退市/停牌日历。

## 5. 单位口径断点（2025-09 起）

`turnover / volume` 的年中位数（比值≈当日均价，单位为"股"时约十几元，为"手"时约 100 倍）：

| 年 | median | p05 | p95 |
|---|---|---|---|
| 2016 | 14.63 | 5.16 | 53.08 |
| 2019 | 9.33 | 3.20 | 39.68 |
| 2022 | 12.60 | 3.36 | 77.39 |
| 2024 | 11.44 | 2.74 | 50.53 |
| 2025 | 19.00 | 3.71 | **2,454.00** |
| 2026 | **848.00** | 9.89 | 5,883.70 |

按月看切换过程（`share_lot_like` = 当日 `turnover/volume > 100` 的行占比）：

```
2025-06  0.0160
2025-07  0.0179
2025-08  0.0240
2025-09  0.1910   ← 开始切换
2025-10  0.7107   ← 跳变
2025-11  0.7084
2025-12  0.7088
2026-01  0.7140
2026-02  0.7142
2026-03  0.7396
2026-04  0.9990   （尾部残片）
```

**这不是一次全局切换日，而是 per-symbol 的渐进迁移**：2025-10 之后约 71% 的行为"手"、
29% 仍为"股"，**同一时点存在两种单位**。因此：

- 2025-09 之前：单位一致（`share_lot_like < 2.5%`）
- 2025-09 之后：量能类特征（volume 派生比率、换手率、vwap 缺口）不可比

同期另一处退化：`is_st` 比例异常塌陷（2026 年仅 0.607%，而 2016-2024 稳定在 3.5-5.0%），
说明状态字段也在同期换了数据源。

**M4-H 的应对**：主评估窗止于 **2025-05-30**，整段位于单位断点之前。

## 6. 财务与背景字段不是 PIT

`financial_source` 分布：

```
tdxgp_heuristic+default    9,472,862   (95.9%)
tdxgp_heuristic              403,622
tushare_pending                2,567
tushare_fina_indicator         2,391   (0.02%)
```

`financial_report_date` 的取值分布：

```
2026-03-02    9,875,062   (99.93%)
（其余为少量空值/零散历史日期）
```

`background_data_source`：`tdxgp_heuristic` 9,439,000 / `akshare_tx_default` 434,829 / …

**结论**：财务字段不是逐日 PIT，而是**同一快照日（2026-03-02）的事后回填**。
凡消费这些列的特征，在历史区间都不满足"当时可得"的证明要求
（用户 §15）。M4-H 的处理是：不因历史年份特征不好而删列/改填法（§16），
但必须报告按 fold 的特征覆盖漂移。

## 7. 基准可用性

`index_daily` 全表仅 **1 个指数**：

```
index_code = 000300.SH    rows = 502    2024-03-04 .. 2026-03-30
```

`daily_bars` 内**不含任何指数行**（`000300` 缺席；`000001` 是平安银行）。
因此依赖 `index_daily` 的 `market_relative` 特征族（属 120 feature schema 的 11 列）
在 2024-03 之前不可计算，**构成按 fold 的系统性特征覆盖漂移**。

## 10. 对本阶段的意义

**可用**：2016-01-04 起的 raw 日线 OHLCV + turnover + float_market_cap，
在 2025-09 之前口径一致，可支撑横截面研究。

**不可用/需规避**：

1. 退市标的缺失 → 幸存者偏差，结论强度受限（不可修复）
2. 2025-09 之后的量能类特征 → 单位混合，主评估窗规避
3. 财务/背景列 → 事后回填，非 PIT
4. `market_relative` 11 列 → 2024-03 前不可计算
5. 涨跌停价、停牌状态 → 需推导/不可区分
6. 尾部残片 → 排除

这些约束已逐条写入 `historical_evidence_inventory.json` 的 `data_defects`，
并在主报告中作为"本证据不支持什么"的依据。
